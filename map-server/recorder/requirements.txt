# rebuilt often enough for a lockfile to be maintained honestly. What IS
# worth doing, once a build works: run
#   docker compose exec recorder-api pip freeze > requirements.lock
# and commit that beside this file. The Dockerfile installs from the lock
# whenever it exists, so every later rebuild gets exactly the working
# set, even after the ranges below have drifted.
